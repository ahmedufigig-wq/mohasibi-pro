# محاسبي PRO — MOHASIBI PRO

تطبيق Android عربي لإدارة البقالة والمبيعات والمخزون والحسابات. المستودع الحالي مبني بـ Kotlin وJetpack Compose (وليس Flutter) حفاظاً على استمرارية المشروع السابق.

## الحالة الفنية
- واجهة Android RTL بهوية كحلية وذهبية.
- قاعدة SQLite محلية مضافة عبر `MohasibiDatabase`، تعمل دون اتصال.
- مخطط بيانات للمنتجات والعملاء والموردين والمبيعات والمشتريات والمخزون والقيود المحاسبية والمصروفات والورديات والمدفوعات وسجل التدقيق.
- دليل حسابات أولي عربي.
- دالة `postSale` تنفذ البيع وتحديث المخزون وحركة المخزون والقيد المزدوج ضمن SQLite transaction واحدة.
- تخزين المبالغ كأعداد صحيحة بالريال اليمني لتجنب أخطاء Float.
- بحث محلي بالاسم والباركود وSKU وإضافة منتج برصيد افتتاحي.

## تنبيه مهم حول الجاهزية
هذا الإصدار يمثل أساساً برمجياً قابلاً للبناء، وليس اعتماداً بأن جميع وظائف نظام ERP قد اكتملت. واجهات بعض الأقسام في التطبيق ما زالت أولية، كما أن تسجيل الدخول الحالي في واجهة العرض غير مربوط بعد بمصادقة آمنة. لا تستخدمه لإدارة أموال متجر فعلي قبل استكمال وربط واختبار الوحدات التالية: المصادقة وتجزئة كلمات المرور والصلاحيات، المشتريات والترحيل المحاسبي لها، مرتجعات البيع، دفعات العملاء والموردين، إغلاق الصندوق، تقارير القوائم المالية، الطباعة الحرارية والماسح والنسخ الاحتياطي والاستعادة والمزامنة، واختبارات المراجعة المحاسبية.

## البناء
- Android Studio + JDK 17.
- افتح المشروع ونفّذ Gradle Sync.
- نفّذ `gradle --no-daemon :app:assembleDebug`.
- الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
- GitHub Actions يبني APK Debug ويرفعه كـ artifact باسم `Mohasibi-PRO-debug-apk`.

## العملة
العملة الافتراضية: الريال اليمني (YER). المبالغ في طبقة البيانات أعداد صحيحة بوحدة الريال.
