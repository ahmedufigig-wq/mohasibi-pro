# محاسبي PRO — MOHASIBI PRO

تطبيق Android لإدارة التجارة والمخزون والمبيعات والحسابات، بواجهة عربية RTL وهوية كحلية وذهبية.

## التقنية
- Kotlin + Jetpack Compose
- Material 3
- Room database للتخزين المحلي (ضمن مراحل التنفيذ)
- دعم العمل دون إنترنت
- العملة الافتراضية: الريال اليمني (ر.ي)

## الوحدات المستهدفة
تسجيل الدخول والصلاحيات، لوحة التحكم، المنتجات والمخزون، نقطة البيع، المشتريات، العملاء والموردون، الديون والتحصيل، المصروفات والصندوق، التقارير، النسخ الاحتياطي، الإعدادات.

## البناء
افتح المشروع في Android Studio ثم نفّذ Gradle Sync وشغّل مهمة `app:assembleDebug`.

> تنبيه: المشروع يبدأ بهيكل تأسيسي. لا تُعد أي وحدة مكتملة حتى يتم تنفيذ منطقها واختبارها.
